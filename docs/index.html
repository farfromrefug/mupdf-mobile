Annotations

Text Search

Full-text search with bounding-rectangle results for precise hit-highlighting in your UI.

Document Editing

Merge, split, reorder pages; insert images; apply permanent redactions.

Quick Start

Five lines to render a PDF

import MuPDFMobile

// 1. Open a document
let doc = try MuPDFDocument.open(path: "/path/to/file.pdf")
print("Pages: \(doc.pageCount)")

// 2. Render page 0 at 2× (Retina)
let page   = try doc.loadPage(at: 0)
let bitmap = page.render(scale: 2.0)
imageView.image = bitmap.image

// 3. Search for text
let hits = page.search(text: "MuPDF")
hits.forEach { rect in highlight(rect) }

// 4. Add a highlight annotation
let rect  = MuPDFRect(x: 72, y: 100, width: 200, height: 20)
let annot = try page.addAnnotation(type: .highlight, rect: rect)
annot.color = MuPDFColor(r: 1, g: 1, b: 0, a: 0.5)
annot.update()

// 5. Save and close
try doc.save(to: "/path/to/output.pdf")
doc.close()
import com.artifex.mupdf.mobile.*

// 1. Open a document
val doc = MuPDFDocument.open("/path/to/file.pdf")
println("Pages: ${doc.pageCount}")

// 2. Render page 0 at 2×
val page   = doc.loadPage(0)
val bitmap = page.render(2f)
imageView.setImageBitmap(bitmap.bitmap)

// 3. Search for text
val hits = page.search("MuPDF")
hits.forEach { rect -> highlight(rect) }

// 4. Add a highlight annotation
val rect  = MuPDFRect(72f, 100f, 200f, 20f)
val annot = page.addAnnotation(MuPDFAnnotationType.Highlight, rect)
annot.color = MuPDFColor(1f, 1f, 0f, 0.5f)
annot.update()

// 5. Save and close
doc.save("/path/to/output.pdf")
doc.close()

Installation

Add to your project in seconds

🍎 iOS — Swift Package Manager 
// Package.swift
dependencies: [
  .package(
    url: "https://github.com/farfromrefug/mupdf-mobile.git",
    from: "1.0.0"
  ),
]
Or add via Xcode → File → Add Packages…
🤖 Android — Gradle / Jitpack 
// settings.gradle
repositories {
  maven { url 'https://jitpack.io' }
}

// app/build.gradle
dependencies {
  implementation 'com.github.farfromrefug:mupdf-mobile:1.0.0'
}
⚠️ Important: After adding the package, initialise the MuPDF submodule: 
git submodule update --init --recursive

API Reference

Unified cross-platform API

The same class names and method signatures on both platforms.

Class iOS Android Description
MuPDFDocument Swift Kotlin Open, save, merge and edit PDF documents
MuPDFPage Swift Kotlin Render, search, and annotate individual pages
MuPDFAnnotation Swift Kotlin Create and edit PDF annotations
MuPDFRenderer Swift Kotlin Utility for full-page and tiled rendering
MuPDFEditor Swift Kotlin Insert images, apply redactions
MuPDFBitmap UIImage Bitmap Platform-native bitmap wrapper
MuPDFRect Swift Kotlin Rectangle value type (x, y, width, height)
MuPDFColor Swift Kotlin RGBA colour value type
MuPDFAnnotationType enum enum class 13 annotation types incl. highlight, redact, ink
